School Management System - Tkinter
==================================

Lab 3 documentation of the Lab 2 Tkinter GUI.

:Author: Marc Bteich
:Version: 1.0.0
:Copyright: 2026, Marc Bteich

The application manages students, instructors and courses. It supports
course registration, instructor assignment, searching, editing, deleting,
and saving or loading records in JSON format.
